# glTF Animation

Open this folder as a project in SatEngine and press **Play**. The beacon’s orange arm swings side to side while the base stays fixed. The three-second clip loops automatically.

Select **Signal Beacon** in the Hierarchy to inspect its Animator. The **Signal** clip comes from [Beacon.gltf](Assets/Beacon.gltf). Click **Play Preview** to start it in the editor, or use the **Time** slider to inspect a pose.
